
 ## AI责任认知互动问卷系统

## 项目简介
本项目面向社科科研数据采集，实现交互式线上问卷+答卷数据入库+后台统计看板。
问卷包含多组情景选择题、责任分配矩阵题，所有作答自动存入数据库；后台支持密码登录，可查看作答分布、均值统计与原始明细数据。

## 核心功能
1. 交互式前端问卷页面，单HTML文件即可在浏览器打开预览
2. 答卷自动提交写入PostgreSQL/金仓数据库
3. 管理员后台：选项分布统计、责任分配均值、条件矩阵汇总、原始答卷导出
4. 同源部署，前端与后端统一域名，无需额外配置跨域

## 运行环境
- Python 3.9+
- 数据库：PostgreSQL 或 金仓数据库(KingbaseES)

## 本地部署步骤
1. 克隆代码到本地
```bash
git clone https://github.com/你的用户名/survey-ai-responsibility.git
cd survey-ai-responsibility
````

2. 配置环境变量 复制配置模板，生成本地配置文件：

```
cp .env.example .env
```

打开.env，填写数据库连接信息、后台口令与 Flask 密钥。

3. 安装依赖

```
pip install -r requirements.txt
```

4. 初始化数据表

```
python setup_survey.py
```

5. 启动服务

```
python app.py
```

- 问卷访问地址：[http://127.0.0.1:5001](http://127.0.0.1:5001)
- 后台统计地址：[http://127.0.0.1:5001/admin](http://127.0.0.1:5001/admin)

## 公网访问说明

仅静态问卷页面可以部署到 GitHub Pages，仅用于预览； 如果需要收集答卷，必须部署 Flask 后端服务。 本地临时公网调试可以使用 cloudflared 隧道，隧道脚本仅保留在本地，不要提交至仓库。

## 数据说明

所有采集数据仅用于学术研究，系统不收集手机号、姓名等个人敏感信息，符合匿名调研伦理规范。
